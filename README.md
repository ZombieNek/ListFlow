# ListFlow 🛒

Минималистичное приложение для списков покупок, которое синхронизируется между устройствами. Заменяет бумажку, которую всегда теряешь, или чат, который вечно нужно листать.

**🌐 Концепция и лендинг:** [корзина.space](https://корзина.space)

---

## Что это и зачем?

Это мой личный проект, который начинался как шаблон, а теперь превращается в рабочий прототип. Я развиваю его **исключительно в этой ветке (master)**, добавляя фичи и улучшая код по мере вдохновения и свободного времени. Коммиты могут быть частыми или с паузами — здесь главное практика и движение вперёд.

## Технологии 

**Технологический стек разработки:**
- **C#** — Основной язык логики приложения.
- **.NET MAUI (.NET Multi-platform App UI)** — Фреймворк для создания нативных приложений из единой кодовой базы.
- **XAML** — Язык разметки для описания пользовательского интерфейса.
